# PAF-IAST Welfare Society website

This is a responsive static website. Open `index.html` in a browser to preview it; no build step or database is required.

## What changed

- Rebuilt the public-site visual identity and removed every demo/admin-facing screen.
- Replaced placeholder copy with a professional, factual Society narrative.
- Built one coherent Get Involved journey: membership, volunteering, and partnership links all preselect the relevant option in one application form.
- Kept general enquiries separate on the Contact page.
- Made form submissions transparent: they prepare an email to `info@paf-iast.edu.pk` rather than pretending to store or submit data.
- Removed invented figures, events, and photo content. Events and stories use honest, polished states until real approved material is supplied.

## Before publishing

1. Confirm that `info@paf-iast.edu.pk` should receive Society applications. If it should go elsewhere, update `recipient` near the bottom of `script.js`.
2. Confirm the cabinet listing on `about.html` for the current term.
3. Add confirmed event details and approved, consented photos to `events.html` and `gallery.html` as they become available.
4. Publish on any standard static host (for example, GitHub Pages, Netlify, or the institute’s web server).

The mission, objectives, advisor, and cabinet baseline were checked against the official PAF-IAST Welfare Society page in September 2026. The final published site should be reviewed by the Society before launch.
